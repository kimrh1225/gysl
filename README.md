# 정각병 학업 시작 지연 성향 분석

대학생의 학업 시작 지연 성향을 살펴보는 정적 웹사이트입니다.

`index.html`을 브라우저에서 열면 시작 화면 → B파트 10문항 → C파트 4개 상황(각 6개 선택) → 결과 및 가이드가 이어집니다. 로그인, 서버, 저장소는 사용하지 않습니다.

## 문항 교체

`survey.js`의 `B`, `SITUATIONS`, `TIMES`, `REASONS`에 원본 PDF의 B·C파트를 반영했습니다. 원본의 자유 입력 시간은 첫 버전의 요구에 맞춰 미리 정한 시간 선택지로 바꿨습니다. 원본의 `기타` 자유 응답은 객관식만 제공한다는 요구에 맞춰 제외하고 `지금 시작할 수 있어서`를 추가했습니다. B파트 각 문항의 `trait`과 `PROFILES`의 설명·가이드는 추후 수정할 수 있습니다.

## 점수와 해석

- H1: B1, B5, B7(역채점)의 산술평균
- H2: B2, B4, B9의 산술평균
- H3: B3, B6, B8의 산술평균
- B10은 계획 습관에 관한 보조 문항으로 표시하며 성향 점수에서는 제외
- 상대적으로 두드러진 성향: 최고점과 차이가 0.25점 이하인 성향을 함께 표시
- C파트: 바로 시작, 정각·30분, 다음 날 선택 횟수, 이유와 각 상황의 응답 평균을 요약. 계획 유무와 부담 수준이 달라질 때의 시작 시각도 비교

점수는 자기이해용 참고 값이며 심리 진단이나 검증된 척도가 아닙니다. 응답은 브라우저 메모리에만 보관되며 새로고침하면 초기화됩니다.

## 화면 구성 자료

PC와 모바일의 실제 렌더링 화면을 모은 [화면 구성 PDF](output/pdf/정각병_홈페이지_화면구성.pdf)가 포함되어 있습니다. 결과 화면은 기능 확인용 예시 응답입니다.

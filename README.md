# 정각병 학업 시작 성향 살펴보기

대학생이 학업 과제를 시작할 때의 생각과 가상 상황에서의 선택을 돌아보는 정적 웹사이트입니다.

## 실행

ES 모듈을 사용하므로 웹 서버로 실행합니다. 예: `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속합니다. 배포용 정적 파일은 `dist/`에 있습니다.

로그인, 데이터베이스, 외부 분석 API는 사용하지 않습니다. 응답은 브라우저 메모리에만 있으며 새로고침하면 사라집니다.

## 설문과 결과

- 최근 한 달의 경험을 묻는 5점 척도 16문항: 계획 실패 민감성 5개, 과제 회피 및 감정 조절 6개, 시간 경계점 선호 5개
- 서로 독립된 4개 상황: 각 상황에서 시작 시각과 가장 중요한 이유를 선택
- 6페이지로 나눈 객관식 설문, 전체 24개 응답의 진행률 표시
- 세 영역의 평균 점수와 수준별 설명, 상황 선택과의 관련성, 조건에 맞는 전략 카드, 성찰 질문

문항과 선택지는 `survey-content.mjs`, 결과 문구는 `feedback-content.mjs`, 계산 및 적용 규칙은 `analysis.mjs`에서 수정할 수 있습니다. 화면은 `survey.js`와 `styles.css`에서 구성합니다.

점수는 P4·A5·T4를 역채점한 영역별 평균입니다. 구간은 반올림 전 점수를 기준으로 낮음 `<2.5`, 중간 `2.5~3.5`, 높음 `>3.5`입니다. 영역 간 순위나 원인 판정은 하지 않습니다. 상황별 선택 이유는 단일 응답이며 실제 행동이나 원인을 확정하지 않습니다.

## 확인

`node --test`로 점수, 구간, 상황 조건, 전략 카드 규칙을 확인할 수 있습니다.
